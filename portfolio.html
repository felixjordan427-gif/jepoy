simple_pos

Java Programming Project · Java Swing
Featured

A desktop point-of-sale application for a burger-stall concept. The cashier clicks menu items on screen, the order is built in a table, the running total updates automatically, and a receipt preview can be sent to the printer.

Features (verified from source)
  • Six menu items with image icons: bacon, burger bundle, Cjoy burger, peach mango pie, spaghetti pan, Famduo
  • Per-item quantity counters on the interface
  • Order table with ID, Item, Qty, and Price columns
  • Add-to-cart logic that merges a repeated item instead of duplicating the row
  • Automatic running total formatted with DecimalFormat
  • Delete a selected order row and reset its counter
  • Receipt preview with store header, itemized list, subtotal, cash, and balance
Concepts demonstrated

Swing components (JFrame, JTable, DefaultTableModel, JButton, JPanel, JTextArea) · ActionListener event handling · GroupLayout · collections and Vector · loops and switch · image resources with ImageIcon · number formatting · exception handling · Nimbus look and feel

05 — Developer Mindset

How I Learn

For me, software development is a loop, not a straight line.

Learn→ Build→ Get it wrong→ Understand what broke→ Improve→ Try again

Most of what I've learned came from broken builds and logic errors, not from tutorials going smoothly. I'm at the stage where bugs are still frequent — but I'm getting faster at reading error messages, tracing problems, and understanding why something failed instead of just copying a fix.
